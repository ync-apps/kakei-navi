# まとめ割ナビ

スマホ・光回線・電気・ガス・カードの組み合わせをすべて計算して、**比べる期間（1年・2年・3年・4年以上）の実質負担が一番安いセット**を提案する無料の Web サイトです。

公開ページ：https://ync-apps.github.io/kakei-navi/

`index.html`（トップページ）と `keisan.html`（計算ツール）をブラウザで開くだけで動きます（サーバー・インストール不要）。データは毎週月曜0時（日本時間）に更新します。
このリポジトリ（ync-apps/kakei-navi）が本体です。以前の置き場所（yoshiki5242/side-business の kakei-navi/）は移設済みです。

## できること

- 家族1人ずつのスマホ（今の会社・データ量）、光回線、電気（電気代・契約アンペア・使用量）、ガスを入力
- スマホ会社（家族1人ずつ別の会社にする案も含む）× 光回線 × 電気 × ガス の組み合わせを計算
- 実質負担 ＝ 月額 × 期間 ＋ 事務手数料・工事費・解約金 − セット割・家族割 − キャンペーン − ポイント
- 結果の内訳はスマホ（人ごと）・光回線・電気・ガス別の小計つき。プラン・割引・キャンペーンは出典ページにリンク
- クレジットカード払いの割引（dカード・au PAY カード・PayPayカード、一般/ゴールド）。「作ってもいい」を選ぶと、年会費と入会特典を含めて得なときだけ提案
- 組み合わせごとの「やることリスト」（カード発行・エントリー・申込・開通後の申請・○か月後の受け取り手続き）。各項目の「DUEMOへ」で1件ずつ DUEMO に登録できる
- 組み合わせごとの「お店で見せる比較図を作る」：今のままとの差、月あたりの比較（棒グラフ）、組み合わせ、割引・特典、初期費用、お店の提案と比べるときのチェックを1枚の画像（PNG）にする（`share-card.js`）。スマホに保存してお店で見せられる
- 「キャンペーン」タブ：特典の一覧（受け取り方つき）、セット割・家族割・カード割引の一覧
- 「比較対象」タブ：地域ごとに比べている会社の一覧（比較に入れていないものの理由は画面に出さず、`data.js` の `notCovered` に管理用として残す）

### 計算のルール

- **電気は各社の料金表で計算**：今の請求額 ＋（乗り換え先の料金表 − 今の会社の料金表）。使用量が空欄なら電気代から推定。燃料費調整額・再エネ賦課金は各社ほぼ共通なので差に含めない
- セット割は同じ種類のものは1つだけ（例：UQ 自宅セット割は光とでんきで二重にならない、ワイモバイルの家族割とおうち割は大きい方）
- 家族割は同じ会社にする人数で計算（みんなドコモ割は ahamo も人数に数える）
- 同じグループ内の乗り換え（ドコモ→ahamo など）は乗り換え特典の対象外
- 光コラボ同士の乗り換えは工事なしの「事業者変更」として工事費0円
- 自分で申請が必要な特典（NURO光の17か月後の手続きなど）は「全額／半分／入れない」を選べる
- 確認できなかった割引・特典（要確認）は標準では計算に入れない

## データについて（データ時点：2026年11月10日）

`data.js` の各項目に確からしさ（`confidence`：high＝公式で確認／mid＝記事で確認・公式の数字から計算／low＝要確認）と出典（`source`）があります。
比較に入れられなかったもの（自動取得を拒否された会社、料金が建物ごとに違うものなど）は `notCovered` に理由つきで入っています（管理用。画面には出しません）。

すべて `data.js` にあります。

| 種類 | 場所 | 主な項目 |
|---|---|---|
| スマホ | `mobileBrands` | `plans`（容量 `capGB`・月額 `price`）、`switchFee` |
| 家族割 | `familyDiscounts` | 人数ごとの割引額（`byCount`）、対象プラン |
| 光回線 | `hikari` | 戸建て/マンションの月額、事務手数料、工事費、提供エリア・住まい |

| ガス | `gas` | 大手都市ガスより何%安いか（`rate`） |
| セット割 | `discounts` | 必要な組み合わせ（`requires`）、割引額、続く月数、`group` |
| キャンペーン | `campaigns` | 金額、現金かポイントか、MNP限定か、受け取り方（`receive`）、条件 |

| 比較対象外 | `notCovered` | 名前と理由 |

### アフィリエイトについて

`affiliate.js` に、ASP で提携した広告リンクを会社ごとに貼り付けます（空なら公式サイトへの普通のリンク）。
リンクがある会社は、やることリストに「申し込む（PR）」ボタンが出て、ページ上部に広告である旨を表示します。おすすめの順位は報酬と関係なく、実質負担の安い順のままです。

会社本体の広告用ページには、公式トップより大きい特典があることがあります（2026年11月13日に A8.net で確認：NURO光の現金55,000円、ビッグローブ光の65,000円＋解約金サポート、ソフトバンクでんきの比較サイト限定割引）。
`data.js` でこれらに `viaLink`（例：`'hikari:nuro'`）をつけていて、`affiliate.js` にその会社のリンクがあるときだけ計算に入れ、「（PRリンクから申し込んだ場合）」と表示します。リンク先と併用できない公式トップの特典には `notWithLink` をつけて外します。
代理店のキャンペーンも、リンクを貼った代理店のものに限り「（代理店「○○」のページから申し込んだ場合）」として計算と順位に入れます（2026年11月13日に方針を変更）。入れるのは、有料オプションなしでもらえると代理店のページに明記された金額だけです。
リンクがある会社は「リンク経由」と「公式経由」の両方を計算し、安い方を結果に使います（同じなら リンク経由）。公式経由の方が安いときは「申し込む（PR）」ボタンを出さず、公式ページへのリンクにします（例：コミュファ光は24か月なら公式Webの980円キャンペーンの方が得、48か月なら代理店経由の方が得）。代理店から申し込むと使えない公式の特典（メガ・エッグの公式Web特典、コミュファ光のWEB限定キャッシュバックなど）には `notWithLink` をつけて外します。
今入れている代理店：ソフトバンク光（NEXT：新規35,000円・転用/事業者変更20,000円、超おうち応援割を使うと15,000円減額＝`reduceIfGroup`）、メガ・エッグ（NEXT：新規20,000円）、ピカラ光（NEXT：新規30,000円）、ドコモ光（アイ・ティー・エックス：新規40,000円・転用/事業者変更25,000円、A8.net審査中）、コミュファ光（エルアイデア：25,000円、審査中）。
auひかり・eo光・BBIQ・ワイモバイル・ドコモでんきは、オプションなしの金額がはっきり書かれた代理店が見つからなかったので入れていません。
`about.html`（運営者・広告について）と `privacy.html` の【　】の部分は、公開前に記入してください。

### DUEMO との連携について

DUEMO（https://ync-apps.github.io/duemo/ ）の「お知らせメールなどの文を貼り付ける」は、貼り付けた文から名前・金額・期限を読み取ります。
・で始まる行が2つ以上あり、それぞれに日付があるときは、項目ごとに分けて一覧で確かめてから**まとめて登録**できます（2026年11月12日に追加）。
- 「全部まとめてDUEMOへ」：全部の手続きを、1行に1つ「・手続き（もらえる特典：〇円・目安：〇年〇月〇日まで）」の形でコピーして DUEMO を別タブで開く（`engine.js` の `todosText`）
- 各項目の「DUEMOへ」：その1件だけを、タイトル／もらえる特典の金額／〇年〇月〇日まで の形でコピーして DUEMO を開く（`todoNotice`）
期限は目安です（申込は1週間後、開通後の手続きは1か月後、「開通から○か月後」の手続きは開通を今日から約1か月後として計算）。
DUEMO の読み取り関数で、テンプレート・金額・期限が正しく入ることを確認済みです。
バックアップの読み込みは今の登録をすべて上書きするため使っていません。ワンタップで登録するには DUEMO 側に「URL からタスクを追加する」機能が必要です。
